# Topics

每個 topic 只描述關心什麼與不要什麼。

## ai

追蹤 AI 模型、AI 工具、coding agent、API 與開發者平台中會改變工作流的更新。

收錄：
- 新模型、能力升級、價格或 API 變化。
- Coding agent、IDE 工具、開發者平台的重大更新。
- 對寫作、研究、開發、自動化有實際影響的產品變化。

不收錄：
- 泛泛 AI 趨勢文。
- 單純融資新聞。
- 沒有官方來源或實測的社群傳聞。

## javascript

追蹤 JavaScript、TypeScript、Node.js、Runtime、Bundler 與前端工具鏈的重要變化。

收錄：

- JavaScript / TypeScript / Node.js / Bun / Deno 版本與重大功能。
- Vite、Rolldown、Turbopack、ESBuild、Rollup 等工具鏈更新。
- 會影響開發流程、build、測試、部署的變更。

不收錄：

- 入門教學。
- 小型套件發布。
- 沒有實作細節的框架比較文。
- React 相關。

## react

追蹤 React、生態系與前端工程實務中會影響實際開發流程的更新。

收錄：

- React release、RFC、compiler、Server Components、Actions。
- Next.js、React Router、TanStack、Remix、Astro 等主流工具重大更新。
- Breaking changes、migration guide、部署平台變化。

不收錄：

- 普通 component 教學。
- 小型 UI library 發布。
- 純觀點文。



## ruby-rails

追蹤 Ruby 與 Rails 的版本、安全、效能、部署、Hotwire 與實務工作流變化。

收錄：

- Ruby / Rails 新版本、patch release、安全更新。
- Active Record、Hotwire、Solid Queue、Kamal、YJIT 的重要變化。
- 官方 release note、guide、核心團隊文章。



不收錄：

- 入門教學。
- 普通 CRUD 範例。
- 小 gem 微小更新。



## gaming-laptop

追蹤電競筆電與高效能行動運算中會影響購買決策的新品、平台與大幅價格變化。

收錄：

- 新 GPU / CPU 行動平台。
- 值得買的新機、完整評測、大幅降價或清庫存。
- 記憶體、SSD、面板、GPU 成本變化對筆電價格的影響。

不收錄：

- 小優惠、普通折扣碼。
- SEO 購買指南。
- 價格不合理但只展示技術的旗艦機。
