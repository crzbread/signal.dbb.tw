## ai

一句話目標：
追蹤 AI 模型、AI 工具、coding agent、API 與開發者平台中會改變工作流的更新。

搜尋方向：
- 主流 AI 實驗室的官方發布與技術突破。
- 開發者工具與 IDE（如 Cursor, VS Code, GitHub Copilot）的重大功能整合。
- 具備生產力突破的新型 Agent 框架或自動化工具。
- 模型 API 價格調整、速率限制變更或新模態能力開放。

收錄：
- 最新一代模型發布或現有模型能力顯著升級。
- Coding agent 或開發環境（IDE）整合 AI 的重大突破。
- 對寫作、程式開發、資料分析有實質效率提升的產品功能變更。
- 官方技術白皮書或關鍵技術架構的正式公開。

不收錄：
- 泛泛的 AI 產業趨勢評論、政策討論或倫理爭議文。
- 單純的企業融資新聞或不具技術細節的合作公告。
- 缺乏官方來源支持或未經實測證實的社群傳聞或爆料。

優先來源：
- OpenAI News: https://openai.com/news/
- Anthropic News: https://www.anthropic.com/news
- Google DeepMind Blog: https://deepmind.google/discover/
- Meta AI Blog: https://ai.meta.com/blog/
- Mistral AI News: https://mistral.ai/news/
- Microsoft Research Blog: https://www.microsoft.com/en-us/research/blog/
- GitHub Blog (Next): https://github.blog/category/next/

重大事件觸發：
- 旗艦級模型家族發布新代號或重大架構更新。
- 關鍵開發工具推出根本性改變開發模式的功能。
- 知名 API 供應商大幅度下調價格或開放關鍵能力限制（如長文本、多模態）。

搜尋關鍵字：
- LLM release, Claude update, GPT model news, Coding Agent, AI SDK, Context Window expansion, AI developer platform
- 模型發布, AI 工具 更新, API 降價, Agent 框架
